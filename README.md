# Zulo - Premium Real Estate Platform

Modern property listing and management platform built with Next.js, Prisma, and Supabase.

## Features

- **Emerald Theme**: Premium visual design using modern CSS.
- **Admin CMS**: Dynamic management of properties and inquiries.
- **Supabase Auth**: Secure authentication for administrators.
- **Next.js 15+**: High-performance SSR and Server Actions.

## Getting Started

1. Clone and install:

```bash
npm install
```

2. Environment:
   Copy `.env.example` to `.env` and fill in your Supabase credentials.

3. Sync Database:

```bash
npx prisma db push
npx prisma db seed
```

4. Run:

```bash
npm run dev
```
